# Felix Elliott

I work on identity engineering: Microsoft Entra, access governance, SSO onboarding and automation. I turn ambiguous controls into small, repeatable systems with evidence a second person can inspect.

I write about design decisions, refusal cases and what the evidence does *not* prove. A green screenshot has its uses; assurance is not one of them.
